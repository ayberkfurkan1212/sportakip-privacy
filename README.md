# SporTakip AI — Gizlilik Politikası

**Son güncelleme:** Ağustos 2026

## Toplanan Veriler

SporTakip AI, WhatsApp üzerinden gönderilen mesajları işler:
- Telefon numarası (kullanıcı kimliği için)
- Yemek ve beslenme bilgileri (kullanıcı tarafından gönderilen)
- Günlük makro ve kalori verileri
- Su tüketimi bilgileri
- Antrenman ve egzersiz kayıtları (tür, set, tekrar, süre)
- Takviye ve supplement bilgileri (kreatin, protein tozu, vitamin vb.)
- Kilo takip verileri

## Verilerin Kullanımı

Toplanan veriler yalnızca:
- Kişisel beslenme ve sağlık takibi için kullanılır
- Antrenman performansı analizi için kullanılır
- Günlük su ve takviye hedeflerini takip etmek için kullanılır
- Üçüncü taraflarla paylaşılmaz
- Reklam amaçlı kullanılmaz

## Veri Güvenliği

Tüm veriler Supabase altyapısında şifreli olarak saklanır.
Row Level Security (RLS) ile kullanıcılar yalnızca kendi verilerine erişebilir.
OpenAI API yalnızca mesaj analizi için kullanılır, veriler saklanmaz.
